# Описание
Небольшой скрипт для упрощения подключения смартфона как веб-камеры для Linux

# Что требуется
- Смартфон с Android
- пк с Linux

Первый запуск потребует включить на Android отладку через USB. После первоночальной настройки, если телефон не выключался, появится возможность сразу подключаться через wifi. 

# Первый запуск

Для начала необходимо установить зависимости: `adb`, `scrcpy`, `v4l2loopback-utils`, `v4l2loopback-dkms`
